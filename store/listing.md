## 詳しい説明（4000字以内）

```
「継続は力なり」——Good-Habitsは、身につけたい習慣をコツコツ積み重ねるためのシンプルな習慣化アプリです。

■ 続けたくなる仕組み
・21日／90日／180日／お試し1日から、習慣ごとに期間を選んで登録
・達成日数の積み上げと、連続達成日数（ストリーク）を同時に記録
・目標日数を達成すると、お祝い演出とともに自動的に習慣が完了
・達成カレンダーでは、1ヶ月分の記録がヒートマップで一目瞭然

■ 頑張りが見えるバッジ
・ストリーク・コース達成・行動回数など、複数の切り口でバッジを獲得
・バッジ画面でいつでも達成状況と進捗を確認できます

■ 続けやすい工夫
・時間帯に応じたメッセージやことわざが、毎回さりげなく背中を押します
・前日にできなかった習慣があれば、次にアプリを開いたときにやさしく知らせます
・ネイビー×ゴールド、グレー×ブルーの2種類のテーマから選べます

■ プライバシーを大切に
・アカウント登録は不要、広告も表示されません
・記録はすべてお使いの端末内だけに保存され、外部のサーバーには一切送信されません
・機種変更や万が一に備えて、設定画面からいつでもデータをバックアップ（書き出し・復元）できます

小さな一歩の積み重ねが、やがて大きな変化になります。今日から、あなたの習慣づくりを始めてみませんか。
```

（約620字）

## 補足（Play Console の各項目への回答方針）

### コンテンツのレーティング（質問票）

広告なし・課金なし・ユーザー生成コンテンツなし・暴力表現や性的表現なし・SNS連携なしのアプリとして回答する。想定される結果は「全年齢対象」。

### データセーフティ

本アプリは `localStorage`（端末内ストレージ）以外にいかなるデータも送信・収集しない（[privacy-policy.html](../privacy-policy.html) 参照）。質問票では以下の方針で回答する。

- 「アプリはユーザーデータを収集していますか？」→ **いいえ**
- 「アプリはユーザーデータを他社と共有していますか？」→ **いいえ**（該当項目なし）
- 暗号化・削除リクエストなどの項目 → データ収集自体がないため、該当なし／対象外として回答

### プライバシーポリシーURL

GitHub Pages で公開する [privacy-policy.html](../privacy-policy.html) のURLを指定する:

```
https://mtateishi-92.github.io/good-habits/privacy-policy.html
```

（GitHub Pagesのリポジトリ名が変わっている場合は実際のURLに置き換える）

### 対象年齢 / ターゲットオーディエンス

子ども向けを意図した機能はないため、一般ユーザー向けとして回答する。

### カテゴリ

「健康 / フィットネス」または「ツール」を想定。最終判断はPlay Console上の選択肢を確認して決める。
