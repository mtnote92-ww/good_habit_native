# Good-Habits

習慣化を助けるPWA（Progressive Web App）です。詳しい仕様は [plan.md](plan.md)、表示文言は [content/messages.md](content/messages.md)、デザインは [mockups/](mockups/) を参照してください。

## 動かし方

ビルド不要の素のHTML/CSS/JSです。ただし **Service Worker（オフライン対応・ホーム画面追加）は `file://` で直接開くと動作しません**。ローカルサーバー経由で開いてください。

```bash
# Python がある場合
python -m http.server 8000

# Node / npx がある場合
npx serve .
```

上記いずれかを実行したら、`http://localhost:8000` をブラウザで開きます。スマートフォンの場合はPCと同じWi-Fiに繋いだ上で、PCのIPアドレス（例：`http://192.168.x.x:8000`）にアクセスし、ブラウザメニューから「ホーム画面に追加」を選ぶとアプリのように起動できます。

VSCodeを使っている場合は拡張機能「Live Server」でも代用できます。

## ディレクトリ構成

```
index.html          アプリ本体（画面はすべてこの1ファイルの中でJSにより切り替え）
manifest.json        PWAマニフェスト（ホーム画面アイコン用）
sw.js                 Service Worker（オフラインキャッシュ）
css/style.css         スタイル一式（2テーマ：classic / modern）
js/
  content.js          メッセージ・称賛コメント・コース定義（content/messages.md と同期させること）
  badges.js            バッジ定義と獲得条件
  icons.js             インラインSVGアイコン集
  storage.js           localStorage への保存・読み込み
  logic.js             ロールオーバー・達成判定・ヒートマップ集計などのコアロジック
  ui.js                 画面描画
  app.js                起動・画面遷移・イベント配線
icons/                 アプリアイコン（icon-512.svg が元データ、gen_icon.py で書き出し）
content/messages.md    表示文言の一覧（企画ドキュメント）
mockups/               デザインモックアップ（Claude Design由来の.dc.html＋閲覧用gallery.html）
```

## 実装済みの機能（plan.md 対応）

- 習慣の登録（4段階の日数コース：21日／90日／180日／テスト用1日）
- 達成延べ日数のカウントダウンと、連続達成ストリークの表示
- 設定した時刻（0〜4時）での日次リストの更新（未達成のToDoを新しい日として再表示、ストリークが途切れた場合はリセット）
- 時間帯別メッセージのランダム表示（全21パターン）＋達成時の称賛コメント（3パターン）
- 目標日数達成時の花火風演出＋対象ToDoの自動削除
- バッジ／実績システム（ストリーク系・コース達成系・行動系・コンプリートの4カテゴリ、バッジ詳細画面で進捗を確認可能）
- 達成カレンダー（月表示のヒートマップ、最長ストリーク・当月達成率の集計）
- テーマ切り替え（ネイビー×ゴールド／グレー×ブルー）
- 前日に未達成の習慣があった場合のアプリ内バナー通知
- `manifest.json` によるホーム画面アイコン追加、Service Workerによるオフライン対応
- データのバックアップ（設定画面からJSONの書き出し／クリップボードコピー／ファイル・テキストからの復元）

エンドユーザー向けの使い方は [how_to_use.md](how_to_use.md) を参照してください。

## 既知の制約

- **OS通知は一切使用しません**：バックエンドを持たない純粋なPWAでは、時刻指定のプッシュ通知も、アプリを閉じている間の通知も実現できません（「前日サボったら翌日10時・12時・21時に通知」「一定時間無操作でリマインド」はいずれも不可）。催促は、次にアプリを開いた際のアプリ内バナー表示のみで行います。正確な時刻通知が必要になった場合は、Web Push配信用のサーバーを別途追加してください。
- **データは端末内保存のみ**：ブラウザのサイトデータを消去すると記録も消えます。機種変更やデータ消去に備えて、設定画面のバックアップ機能で定期的にJSONを書き出してください（手順は [how_to_use.md](how_to_use.md)）。自動同期は行いません。
- アプリアイコンは `icons/icon-512.svg` を元に `icons/gen_icon.py`（Pillow使用）で書き出しています。デザインを変更する場合はどちらかを編集し、再生成してください。
